# MVP Components Demo

Form-oriented demo for the Store + Reducer pattern with `ForField(...)` bindings.

## Run

```bash
go run ./examples/mvp_components_demo
```

## Covered Components

- `Input`
- `Textarea`
- `Select`
- `Checkbox`
- `DatePicker`
- `TimePicker`

## What It Shows

- Field-driven state updates via `FieldChangeIntent`
- Controlled form fields backed by `Store[T]`
- Popup components inside a larger form
- Interaction mode switching for mouse and keyboard workflows
