# Layer Z-Order Test Demo

Layer Z-Order 测试演示，用于验证层级顺序和覆盖效果。

## 编译运行

```bash
cd examples/fiber_firsts/layer_zorder_test
go build -o main.exe
./main.exe
```

## 测试用例

### 测试 1: 基础层级顺序

验证从下到上的 5 个层级（Layer 0-4）是否正确显示：
- Layer 0 (Base) 在最底层
- Layer 4 (Inspector) 在最顶层
- 层级按 0→1→2→3→4 顺序排列

**预期结果**：高层元素覆盖低层元素

### 测试 2: 同位置覆盖测试

验证相同位置的多层元素，顶层元素是否可见：
- 3 个 Toast 在接近的视觉位置
- 只有顶层的内容可见
- 低层内容被正确覆盖

**预期结果**：相同位置时，层级高的元素可见

### 测试 3: Modal 背景灰化

验证 Modal 背景灰化机制：
- Modal 上方区域应灰色
- Modal 左侧区域应灰色
- Modal 右侧区域应灰色
- Modal 下方区域应灰色
- Modal 内部区域保持原色

**预期结果**：Modal 四周正确灰化，内部不被影响

### 测试 4: 中文显示测试

验证 Modal 中的中文字符处理：
- 中文字符宽度正确（每个字符占 2 列）
- 中文字符不出现乱码或截断
- Modal 背景灰化不破坏中文字符连续性

**预期结果**：中文正确显示，背景灰化正常工作
