# Date + Time Picker Demo

Minimal demo showing `DatePicker` and `TimePicker` working together with `FieldChangeIntent`.

## Run

```bash
go run ./examples/date_time_picker_demo
```

## What It Covers

- Controlled `DatePicker` bound to `schedule.date`
- Controlled `TimePicker` bound to `schedule.time`
- Store + Reducer state updates from field binding
- Direct typing and popup-based selection
