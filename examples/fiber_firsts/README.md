# Fiber-First Runtime Examples

This directory keeps Fiber-first examples that are still useful for runtime-level behavior:

| Example | Purpose |
|---|---|
| `focus_switching_demo` | Focus routing with Store + Reducer state |
| `layer_render_demo` | Layered rendering path |
| `layer_visual_demo` | Visual layer ordering demo |
| `modal_demo` | Modal rendering and behavior |
| `modal_positioning_demo` | Modal placement behavior |
| `portal_demo` | Portal rendering and hit-test behavior |

Low-level one-component layout probes such as `absolute_demo`, `border_demo`, `grid_demo`, `panel_demo`, `scrollview_demo`, `stack_demo`, `table_demo`, and the early `fiber_first_demo` were archived under `../../docsArchive/cleanup-2026-05-19/_examples/fiber_firsts/`.

For SDK-level learning, prefer:

- `../layout_demo`
- `../layout_component_fixtures_demo`
- `../mvp_components_demo`
- `../ui_demos`
