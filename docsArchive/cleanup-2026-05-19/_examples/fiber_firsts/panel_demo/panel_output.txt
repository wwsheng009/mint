======================================================================
Panel Component Features:
======================================================================
  Layout Options:
    - Width/Height: Fixed dimensions
    - Height=0: Auto height based on content
    - Flex: Flex factor for expansion
    - Padding: Inner padding

  Border Styles:
    - Rounded: ╭╮╰╯ (default for titled panels)
    - Single:  ┌┐└┘
    - Double:  ╔╗╚╝
    - None:    No border

  Content Areas:
    - Header: Optional header component
    - Content: Main content (required)
    - Footer: Optional footer component

  Styling:
    - BorderColor: Color of the border
    - Title: Sets title (appears in border label)
    - Label: Custom border label

  Convenience Functions:
    - panel.Of(content)
    - panel.OfSize(content, w, h)
    - panel.Titled(title, content)
    - panel.Bordered(content, w, h)
