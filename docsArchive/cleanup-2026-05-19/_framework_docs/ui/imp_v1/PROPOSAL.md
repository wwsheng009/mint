## 一、执行摘要

### 1.1 提案概述

本提案旨在将 Mint TUI Framework 从当前的传统命令式架构升级为**现代声明式架构**，借鉴 React/Vue 等前端框架的设计理念，为终端应用开发提供更高效、更易维护的编程模型。

### 1.2 核心价值

| 维度 | 当前状态 | 目标状态 | 提升 |
|------|---------|---------|------|
| 开发效率 | 命令式，代码冗余 | 声明式，代码精简 | 50%+ |
| 组件复用 | 继承耦合，复用困难 | 函数组件，Hooks 复用 | 3x |
| 状态管理 | 分散，易出错 | 集中式，单向流 | 稳定性↑ |
| 渲染性能 | 全量重绘 | 增量 Diff + 虚拟化 | 10x+ |
| 学习曲线 | 组件树复杂 | 声明式，直观 | 易学性↑ |

### 1.3 建议决策

**建议**: 批准本提案，启动 8 周实施计划

**理由**:
1. 架构设计完整，所有核心模块已有详细设计文档
2. 现有基础设施可复用 60%+，风险可控
3. 渐进式迁移，新旧代码可共存
4. Demo 验证通过，所有设计目标可实现

## 二、背景与动机

### 2.1 现状分析

#### 当前架构特点

```
┌─────────────────────────────────────────┐
│         Mint 当前架构                   │
├─────────────────────────────────────────┤
│  ✅ 成熟的事件系统                     │
│  ✅ 稳定的布局引擎 (Flex)                │
│  ✅ 高效的终端渲染                     │
│  ✅ 完整的 DevTools 支持               │
│  ❌ 缺少声明式 UI 层                   │
│  ❌ 组件复用困难                        │
│  ❌ 状态管理分散                        │
│  ❌ 渲染性能未优化                      │
└─────────────────────────────────────────┘
```

#### 核心问题

**问题 1: 命令式 UI 开发效率低**

```go
// 当前：命令式
container := display.NewVBox(
    display.NewPadding(2),
)
title := display.NewText("Hello World")
title.SetStyle(titleStyle)
container.Add(title)
content := display.NewParagraph("Content")
container.Add(content)
```

```go
// 目标：声明式
func App() VNode {
    return ui.VStack(
        ui.Text("Hello World").Style(titleStyle),
        ui.Text("Content"),
    ).Padding(2)
}
```

**问题 2: 组件状态管理分散**

```go
// 当前：状态分散在各个组件中
type MyComponent struct {
    count    int
    items    []string
    loading  bool
    // ... 很多状态字段
}

func (c *MyComponent) UpdateCount() {
    c.count++
    // 需要手动触发刷新
}
```

```go
// 目标：Hooks 集中式状态管理
func MyComponent() VNode {
    count, setCount := ui.UseState(0)
    items, setItems := ui.UseState([]string{})
    // 状态更新自动触发重新渲染
}
```

**问题 3: 渲染性能瓶颈**

当前：全量重绘 → 大界面卡顿

目标：增量 Diff + 虚拟化 → 流畅 60 FPS

### 2.2 行业趋势

| 框架 | 架构 | 生态 |
|------|------|------|
| React | 声明式 + Hooks | 成熟 |
| Vue | 声明式 + Composition | 成熟 |
| Flutter | 声明式 + Widget | 成熟 |
| **终端 TUI** | **传统命令式** | **待革新** |

**机遇**: 终端 TUI 领域尚无成熟的声明式框架，Mint 有机会成为先驱。

## 三、目标与范围

### 3.1 核心目标

1. **声明式 UI 系统**
   - 函数组件
   - JSX 风格的 VNode
   - 单向数据流

2. **React Hooks 机制**
   - useState, useEffect, useContext
   - useMemo, useCallback, useRef

   - Fiber 并发渲染

### 4.1 架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    Application Layer                          │
│                   (用户代码 - examples/)                      │

│  • useState, useEffect, useContext                            │
│  • Text(), Button(), Input()                                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                   Framework Layer                            │
│              (声明式框架 - framework/)                        │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Reconciler      │  Hooks    │  Layout   │  Render  │    │
│  │  • Diff算法      │  • State   │  • Flex   │  • DrawCmd│    │
│  │  • Fiber        │  • Effect  │  • Grid   │  │        │    │
│  │  • Scheduler    │  • Context │  • Abs    │  │        │    │
│  └─────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Layer System   │  Editor   │  Event    │  Style   │    │
│  │  • Modal        │  • Buffer │  • Dispatch│  • Theme  │    │
│  │  • Tooltip      │  • Cursor │  │         │  │        │    │
│  │  • Toast        │  │         │  │         │  │        │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                    Runtime Layer                             │
│               (运行时核心 - runtime/)                         │
│  • Platform • Paint • Event • Focus • Layout                │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 核心模块

#### Reconciler (协调器)

- VNode Diff 算法
- Fiber 树结构
- Lane 优先级调度
- 时间切片 (Time Slicing)

#### Hooks (状态钩子)

- useState: 本地状态
- useEffect: 副作用处理
- useContext: 上下文共享
- useMemo/useCallback: 性能优化

#### Layout (布局系统)

- Flex: 一维布局
- **Grid**: 二维布局 (新增)
- **Absolute**: 绝对定位 (新增)

#### Layer System (层级系统)

- Modal: 模态框
- Tooltip: 提示框
- Toast: 通知

#### Render (渲染管线)

- DrawCmd 生成
- Buffer Diff
- **Style Diff**: 终端输出优化

#### Input (输入系统)

- TextBuffer: UTF-32 文本缓冲
- Cursor: 光标管理
- Selection: 选择区
- History: 撤销/重做

### 4.3 技术亮点

#### 1. Style Diff 优化

```go
// 问题：大量重复的 ANSI 代码
"\033[31mHello\033[0m \033[31mWorld\033[0m"  // 25 字节

// 解决：状态跟踪 + RLE 编码
状态: { Fg: Red }
输出: "Hello World"                           // 11 字节
减少: 56%
```

#### 2. 输入优先级调度

```
输入事件 > 交互事件 > UI 更新 > 后台任务
```

保证用户操作永远响应流畅。

#### 3. 增量语法高亮

```go
// 只解析修改的行
onLineChanged(lineNumber):
    lexer.Retokenize(lineNumber)

// 状态自动传播到后续行
// 直到状态稳定
```
