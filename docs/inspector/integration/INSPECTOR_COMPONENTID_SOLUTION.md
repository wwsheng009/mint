# Inspector UniqueID: ComponentID Solution

## User's Key Insight

> "why not use the useState function"

You were absolutely right! The **state management system** already has stable, unique identifiers: **ComponentID** from `ComponentContext`.

## The Problem with Previous Approaches

### Issue: `vstack.bordered.vstack[0]` Collision

```go
VStack(
    Bordered(VStack(...)),  // Generates: vstack.bordered.vstack[0]
    Bordered(VStack(...))   // Generates: vstack.bordered.vstack[0] ← COLLISION!
)
```

Both nested VStacks get the same path + index because they're both the first child of their respective Bordered parents.

## Solution: Use ComponentID from State System

### How ComponentID Works

The Mint TUI state management system already generates stable, unique IDs:

```go
// From runtime/ui/hooks.go
type ComponentContext struct {
    ComponentID string  // Unique ID: "name-sequential-number"
    Hooks       []Hook
    HookIndex   int
    RenderCount int
}

func NextComponentID() string {
    globalComponentID++
    return fmt.Sprintf("comp-%d", globalComponentID)
}
```

**Key Properties**:
- ✅ Generated by the state management system (like useState)
- ✅ Tied to ComponentInstance (persists across renders)
- ✅ Unique for each component instance
- ✅ Stable across VNode rebuilds

### Implementation

**File**: `internal/inspector/tree_view.go:62-117`

```go
func (tv *TreeView) buildTree(vnode ui.VNode, parent *TreeNode, level int, path string, index int) *TreeNode {
    // Get current component context for stable ComponentID
    var componentID string
    if ctx := rtui.GetCurrentContext(); ctx != nil {
        componentID = ctx.ComponentID  // Uses state management system!
    }

    // Generate UniqueID with ComponentID
    var uniqueID string

    // Priority 1: User-defined key (most stable)
    if key := vnode.Key(); key != "" {
        uniqueID = fmt.Sprintf("%s[%s]", nodePath, key)
    }

    // Priority 2: ComponentID + path + index (uses useState infrastructure)
    if uniqueID == "" && componentID != "" {
        // Example: "MyComponent-comp-3.vstack.text[0]"
        uniqueID = fmt.Sprintf("%s.%s[%d]", componentID, nodePath, index)
    }

    // Priority 3: Fallback to path + index (non-component VNodes)
    if uniqueID == "" {
        uniqueID = fmt.Sprintf("%s[%d]", nodePath, index)
    }

    node := &TreeNode{
        UniqueID:     uniqueID,
        ComponentID:  componentID,  // Store for debugging
        // ...
    }
}
```

## Why This is Better

| Approach | Collision Proof | Stable | Uses State System |
|----------|----------------|--------|-------------------|
| Counter | ✅ No | ❌ Changes every rebuild | ❌ No |
| Path-only | ❌ Yes | ✅ Yes | ❌ No |
| Path + Index | ❌ Yes (nested) | ✅ Yes | ❌ No |
| **ComponentID** | ✅ **Yes** | ✅ **Yes** | ✅ **Yes** |

## How It Relates to useState

ComponentID is generated by the same system that provides useState:

```go
// When a component renders:
func MyComponent() ui.VNode {
    // 1. ComponentContext is created/retrieved
    ctx := GetCurrentContext()  // Has ComponentID

    // 2. useState uses this context
    state, setState := ui.UseState(initial)

    // 3. Inspector can access same ComponentID
    // This makes UniqueIDs stable like state!
}
```

**Key Insight**: ComponentID is tied to ComponentInstance, just like state. When the component re-renders:
- VNode is recreated
- But ComponentInstance persists
- So ComponentID stays the same
- Therefore UniqueID stays the same

## Architecture Benefits

### 1. Leverages Existing Infrastructure

- No need to create our own ID system
- Uses the same ComponentID as useState/useReducer
- Benefits from state system's stability guarantees

### 2. True Uniqueness

- ComponentID is globally unique (counter-based)
- Different component instances always have different IDs
- Even identical structures get different IDs

### 3. Stable Across Renders

- ComponentID persists with ComponentInstance
- VNode recreation doesn't affect ComponentID
- Expand state correctly persists

### 4. Debuggable

- Status line shows: `Focus: #3 [ID: MyComponent-comp-5.text[0]]`
- Clear which component instance
- Easy to track in logs
