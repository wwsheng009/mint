好，接下来这块是 **TUI 引擎真正的“硬核区”之一**：

> ⌨️ **复杂输入系统（Input / Form / 光标 / IME）**

如果弹层系统解决的是“视觉与交互层级”，
输入系统解决的是：

> **“如何让终端里的输入体验像 GUI 应用一样自然”**

这块做不好，所有“高级 UI”都会显得业余。

---

# 🧠 先理解一个现实

终端输入 ≠ GUI 输入。

终端给你的只是：

```
字节流 / key code
```

而你要做的是：

```
文本编辑器级输入体验
```

包括：

* 光标移动
* 文本选区（可选）
* 删除规则
* 中英文输入（IME）
* 焦点切换
* 粘贴
* 多行支持

所以 Input 不是一个“组件”，而是：

> 🧱 **一套子系统**

---

# 🧩 一、Input 组件的引擎职责划分

| 层级       | 职责               |
| -------- | ---------------- |
| SDK      | 提供 `<Input>` API |
| State    | 存储文本与光标位置        |
| Layout   | 计算可见文本区域         |
| Render   | 绘制文本 + 光标        |
| Event    | 处理键盘输入           |
| Platform | 解析终端 key 序列      |

---

# ✏️ 二、文本模型（核心数据结构）

不能只存 string，必须：

```go
type TextBuffer struct {
    Runes []rune
    Cursor int   // 光标位置（逻辑 index）
}
```

为什么？

因为：

* UTF-8 多字节
* 删除/移动不能按 byte

---

# ➡️ 三、光标移动规则

支持：

| 键         | 行为       |
| --------- | -------- |
| ← →       | rune 级移动 |
| Ctrl+← →  | 单词移动     |
| Home/End  | 行首尾      |
| Backspace | 删除前一字符   |
| Delete    | 删除后一字符   |

---

# 🌏 四、IME（中日文输入）支持原理

终端 IME 本质是：

> 输入法在客户端处理 → 最终提交字符串

你不会拿到“拼音过程”，只会收到：

```
完整的字符序列
```

所以引擎需要：

```
正确处理多 rune 插入
```

不要假设每次输入只有一个字符。

---

# 🧠 五、可视区域裁剪（长文本）

当输入内容超过组件宽度：

```
需要水平滚动窗口
```

数据：

```go
VisibleStart int
VisibleEnd   int
```

渲染只画这一段。

---

# ✨ 六、光标渲染（终端特殊处理）

终端只有一个“硬件光标”，但 UI 有多个 Input。

所以引擎做：

```
逻辑光标 → 计算绝对屏幕坐标 → 移动终端光标
```

并且：

* 非聚焦 Input 不显示光标
* 光标闪烁可由终端负责

---

# 📋 七、Input 与 Focus 系统结合

Input 只是：

```
FocusNode 的一种
```

获得焦点时：

```
开始接受 Key 事件
```

失焦时：

```
停止编辑
```

---

# 📦 八、SDK API 设计

```go
value, set := ui.UseState("")

ui.Input().
    Value(value).
    OnChange(set).
    Placeholder("Enter name...")
```

---

# 🧠 九、事件处理流程

```
Key Event
  ↓
FocusManager 找到当前 FocusNode
  ↓
Input.HandleKey(event)
  ↓
更新 TextBuffer
  ↓
setState → re-render
```

# 🧨 十、几个必须提前避开的坑

| 坑                 | 结果      |
| ----------------- | ------- |
| 用 string index 操作 | 中文删除错位  |
| 不做水平滚动            | 长输入错位   |
| 光标位置按字节           | Emoji 崩 |
| 没焦点系统             | 输入乱飞    |

---

# 🧩 十一、Form 系统怎么来？

Form 不是新系统，只是：

```
多个 Input + Focus 顺序 + Submit 行为
```

Tab 切换由 FocusScope 控制。
