# 一、🔥 Diff + Partial Render（只重绘脏区域）

核心目标：

> ❗ 不要每帧全量重绘
> ✅ 只更新“变化的节点 + 覆盖区域”

---

## 1️⃣ Fiber Diff（O(n)）

采用“同层线性 diff”（和 React 类似，但更简单）

```go
type Fiber struct {
    Key   string
    Type  string

    Props any

    StateNode *LayoutBox

    Child, Sibling *Fiber
}
```

---

### 核心 Diff（同层）

```go
func diffChildren(old, new []*Fiber) (ops []Op) {

    i := 0
    for i < len(old) && i < len(new) {
        if same(old[i], new[i]) {
            ops = append(ops, Update(old[i], new[i]))
        } else {
            break
        }
        i++
    }

    // 新增
    for ; i < len(new); i++ {
        ops = append(ops, Insert(new[i]))
    }

    // 删除
    for ; i < len(old); i++ {
        ops = append(ops, Delete(old[i]))
    }

    return
}
```

👉 保持 O(n)，避免 map（除非 key reorder）

---

## 2️⃣ 脏标记（Dirty Flag）

```go
type LayoutBox struct {
    AbsX, AbsY int
    W, H int

    Dirty bool
}
```

---

### 标记策略

```go
func markDirty(n *LayoutBox) {
    for n != nil {
        n.Dirty = true
        n = n.Parent
    }
}
```

👉 **向上冒泡**（因为父可能影响裁剪）

---

## 3️⃣ 脏区域收集（Dirty Rect）

```go
type Rect struct {
    X, Y, W, H int
}
```

```go
func collectDirty(nodes []*LayoutBox) []Rect {
    var rects []Rect

    for _, n := range nodes {
        if n.Dirty {
            rects = append(rects, Rect{n.AbsX, n.AbsY, n.W, n.H})
        }
    }

    return mergeRects(rects)
}
```

---

## 4️⃣ 合并矩形（减少 draw call）

```go
    // 简化版：相交就合并
}
```

---

## 5️⃣ 局部渲染

```go
func RenderPartial(rects []Rect, nodes []*LayoutBox) {
    for _, r := range rects {
        for _, n := range nodes {
            if intersect(n, r) {
                draw(n)
            }
        }
    }
}
```

---

## 🚨 核心优化点

👉 **不是“只画 dirty node”**
👉 而是：

> 🔥 “重画 dirty 区域内的所有可见节点（按 Z）”

否则会出现“残影”

# 二、🔥 Clip / Scroll / Virtual List

---

## 1️⃣ Clip（裁剪系统）

每个节点增加：

```go
type LayoutBox struct {
    Clip Rect
}
```

---

### Clip 计算（关键）

```go
func computeClip(node *LayoutBox) {
    if node.Parent == nil {
        node.Clip = Rect{0, 0, rootW, rootH}
        return
    }

    node.Clip = intersectRect(
        node.Parent.Clip,
        Rect{node.AbsX, node.AbsY, node.W, node.H},
    )
}
```

---

👉 结果：

> 子节点永远不会画出父边界

---

## 2️⃣ Scroll（滚动本质）

```go
type LayoutBox struct {
```

---

### 子节点布局

```go
child.AbsY = parent.AbsY + child.Y - parent.ScrollY
```

## 3️⃣ Virtual List（大数据核心）

---

### ❌ 错误做法

```go
for i := 0; i < 100000; i++ {
    renderItem(i)
}
```

---

### ✅ 正确：只渲染可见区域

---

## 计算可见范围

```go
start := scrollY / itemHeight
end   := (scrollY + viewportH) / itemHeight
```

---

## 渲染

```go
for i := start; i <= end; i++ {
    renderItem(i)
}
```

## 偏移（关键）

```go
y := i*itemHeight - scrollY
```

👉 这就是：

> 🔥 **虚拟滚动（O(visible) 而不是 O(n)）**

# 三、🔥 动画系统（基于 LaneIdle）

---

## 1️⃣ 动画本质

```go
type Animation struct {
    Start time.Time
    Duration time.Duration

    From, To float64

    Easing func(t float64) float64
}
```

---

## 2️⃣ 每帧更新

```go
func (a *Animation) Value(now time.Time) float64 {
    t := float64(now.Sub(a.Start)) / float64(a.Duration)

    if t > 1 {
        t = 1
    }

    return a.From + (a.To-a.From)*a.Easing(t)
}
```

---

## 3️⃣ 绑定到 Layout

```go
node.X = anim.Value(now)
markDirty(node)
```

---

## 4️⃣ 调度优先级

```go
animFiber.Lane = LaneIdle
```

---

👉 意味着：

* 输入（LaneInput）永远优先
* 动画不会卡 UI

## 5️⃣ 常用 easing

```go
func EaseOut(t float64) float64 {
    return 1 - (1-t)*(1-t)
```

# 四、🔥 三者融合（关键设计）

---

## 一帧完整流程

```go
func Frame(now time.Time) {

    // 1️⃣ 输入（最高优先级）
    processInput()

    // 2️⃣ 动画更新（LaneIdle）
    updateAnimations(now)

    // 3️⃣ Fiber 调度
    schedule()

    // 4️⃣ Layout
    Layout(root)

    // 5️⃣ Flatten + Sort
    nodes := Flatten(root)
    Sort(nodes)

    // 6️⃣ Dirty 收集
    rects := collectDirty(nodes)

    // 7️⃣ 局部渲染
    RenderPartial(rects, nodes)

}
```
