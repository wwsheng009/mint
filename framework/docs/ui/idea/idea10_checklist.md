# ☠️ 一级地雷（会直接把系统拖垮）

---

## 1️⃣ Unicode & 宽字符问题（终端第一大坑）

终端不是“一个字符=一个格子”。

| 类型             | 宽度           |
| -------------- | ------------ |
| ASCII          | 1            |
| 中文/日文          | 2            |
| emoji          | 2（甚至 0 + 组合） |
| combining mark | 0            |

如果你的 Layout/DrawText 仍然：

```go
x += len(text)
```

那：

* 光标错位
* 布局错乱
* Diff 失效

### 必须做：

* grapheme cluster 分割
* wcwidth 计算缓存
* Cell 中支持“占位 continuation”

---

## 2️⃣ 行尾换行与自动滚屏

终端在最后一列写字符会：

```
自动换行 + 滚屏
```

会破坏你对 Buffer 的控制。

### 解决：

* 永远用绝对光标定位
* 禁止依赖终端自动行为

---

## 3️⃣ Resize 风暴

拖动终端窗口时：

```
一秒几十次 resize 事件
```

如果每次都：

```
Layout + Diff + Paint
```

UI 会卡死。

### 需要：

* Resize debounce
* 仅标记 dirty，不立即重排

---

## 4️⃣ 滚动性能“假死”

虚拟列表没问题，但：

```
每帧 Text Measure
```

是最大 CPU 黑洞。

### 必须：

* 文本测量缓存
* 行高缓存
* 可见区域剪枝

---

# ⚠️ 二级地雷（后期难改）

---

## 5️⃣ Focus 系统不先设计

没有完整焦点树：

* 键盘事件混乱
* Tab 顺序不可控
* Modal 难实现

需要：

```
FocusManager + FocusScope
```

---

## 6️⃣ Z-Index / 覆盖关系

终端是“平面画布”，但 UI 需要：

* Modal
* Tooltip
* Dropdown

没有 **Layer System**，后面会推翻渲染模型。

---

## 7️⃣ Clip（裁剪）机制

没有 Clip：

* 滚动溢出
* 子组件绘制越界

Clip 必须在 RenderCmd 阶段支持。

---

## 8️⃣ 时间源统一

动画、Scheduler、事件节流如果用不同 time source：

→ 抖动、不同步

需要统一 `FrameClock`。

---

# 🧠 三级地雷（规模变大才爆）

---

## 9️⃣ 内存泄漏

RNode / Hook / Animation 没清理：

```
长时间运行 → 内存涨
```

需要：

* Destroy 生命周期
* Weak 引用检查

---

## 🔟 Diff Key 设计

列表没有稳定 key：

```
节点错复用 → 状态错乱
```

这是 React 的经典坑。

---

## 1️⃣1️⃣ Style 级联过深

Style 解析层级过多：

```
每帧解析样式树 → 性能掉
```

必须：

* 扁平 token
* Style cache

---

## 1️⃣2️⃣ IO 阻塞

终端写入是 IO：

如果 Raster 后直接 Write：

→ 阻塞 UI 主循环

需要：

* 输出缓冲
* 非阻塞 flush

---

# 🚨 终端特有隐藏坑

| 问题               | 描述        |
| ---------------- | --------- |
| ANSI 状态不同步       | 颜色/样式残留   |
| 光标显示状态           | 闪烁、隐藏恢复   |
| Windows vs Linux | ANSI 支持差异 |
| SSH 延迟           | 网络抖动      |
| 终端 bug           | 不同终端行为不同  |

* 在 Layout 读动画值

整个调度模型就会崩。
